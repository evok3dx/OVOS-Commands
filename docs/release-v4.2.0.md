# Jarvis 4.2

## Changes

- A cleaner Dashboard, Light/Dark mode in General and subtle Unchained branding.
- Private session activity for app, reading and dictation results.
- Correct Standard Notes window recognition and shorter failure feedback.
- ElectronMail included under Mail and removed from Office.
- Readable report folders and an Isolation status/check in Maintenance.

## Verification

Candidate checks are pending; this release has not been published.
The reviewed runtime and Media/File Search versions are retained.
Live GUI and Notes acceptance remain separate from automated checks.
