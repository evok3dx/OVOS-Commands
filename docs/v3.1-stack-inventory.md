# Brain package inventory for V3.1

**VERIFIED snapshot:** 110 Python distribution versions recorded by the
24 September 2026 Brain audit. This records installed packages, **not** which
services were active, whether each package is needed on a laptop, or what a
fresh install should pull. Package names use the snapshot's distribution
metadata spelling; underscore and hyphen spellings may refer to the same
normalised Python distribution.

Each line remains PENDING for V3.1 until the installer policy, a fresh-host
result and the upgrade result are checked. “Core candidate” and “Voice
candidate” identify versions to evaluate together first, not an instruction
to change the current machine. “Review installed role” means check its role
against Brain's actual configuration and services before deciding whether to
install, preserve or leave it as an optional add-on. The audit lists
`ovos-skill-jarvis-dispatcher 2.3.1` because that was installed on Brain when
the snapshot was taken; V3.1 must package and install its own reviewed version.

## Package decisions that need extra evidence

- **PhōnNX:** Brain's `phoonnx-1.93.0a1.dist-info/direct_url.json` records
  `https://github.com/TigreGotico/phoonnx.git` at commit
  `ce0568ae7a552bce79ccf40d13b785c61dbb9e77`; verify the source and
  dependencies before installing it elsewhere. A version string alone does
  not prove the same build.
- **Media:** Installed `ovos-media` and its providers do not establish that
  the standalone media daemon was in use. Brain's tested playback retained
  `ovos-audio`/OCP. Preserve its effective routing and the two separately
  bundled Jarvis Media and File Search plugins; compare their installed
  versions independently.
- **Voice:** Preserve existing downloaded models, OpenWakeWord and Whisper
  configuration, local Whisper hint hook, Bella fallback and custom sound.
  The recorded OpenWakeWord/NumPy metadata conflict still needs testing;
  do not claim a clean dependency graph solely from Brain's playback.
- **Inventory use:** A replacement OVOS virtualenv must compare every row
  above to the target and report missing, mismatched and intentionally
  excluded packages. Do not report the installed list as a completed
  reproduction of the running system.
