# Jarvis 3.6 final release checklist

This is the active release gate. It reconciles the historical
[3.1](v3.1-checklist.md), [3.1.1](v3.1.1-checklist.md) and
[V2 parity](v2-to-v3-parity-audit.md) records without deleting their failure
history.

Status meanings:

- **VERIFIED**: confirmed by source plus an automated test or recorded live
  result.
- **PLANNED**: accepted but not implemented or not yet tested at its real
  boundary.
- **HISTORICAL**: an older failure or approach retained for context.

## Release blockers

- [x] Repository validation, package imports and all focused tests pass.
- [x] The complete 340-variation non-executing routing simulation passes its
  policy gate and saves a report.
- [x] A final archive and SHA-256 sidecar are built from the release source;
  after this evidence update they are rebuilt once from the committed
  source; the archive is extracted and tested as an ordinary download.
- [x] Fresh install, update preservation, failure recovery, rollback and
  uninstall tests pass from the extracted archive.
- [x] Tracked files contain no user names, real home paths, IP addresses,
  credentials, private helper source or reference-machine branding.
- [ ] `main`, annotated tag `v3.6.0` and the GitHub release all identify the
  same commit and checksum.

## Voice, routing and everyday behaviour

- [x] **VERIFIED:** native intents run first, Faster-Whisper supplies local
  text, bounded Qwen handles natural variants, and unmatched recognised
  commands receive “Please repeat.” Empty/noisy captures stay silent.
- [x] **VERIFIED:** Qwen can select only registered actions for enabled apps.
  It cannot emit shell commands, arbitrary paths or unreviewed keystrokes.
- [x] **VERIFIED:** newly detected apps and saved spoken names flow into the
  same bounded app-action catalogue and Whisper hints after saving.
- [x] **VERIFIED:** one-turn writing and Hermes, Claude Desktop and enabled
  private-agent message starters retain focus checks. Dictated message content
  is never sent through Qwen.
- [x] **VERIFIED:** ordinary reading preserves the user's Speech Note speed;
  requested 2× is temporary and restores the exact prior value. Lock
  contention, empty selection and startup failure have distinct outcomes.
- [x] **VERIFIED:** the Voice guide preserves Speech Note's opaque settings
  and explains the one regex rule that removes the wake phrase and optional
  punctuation during continuous dictation.
- [x] **VERIFIED:** Browser, Notes, Mail, Calendar and Office have explicit
  compatible preferred-app selectors. “Open browser” uses the chosen enabled
  browser; generic aliases never point at two apps simultaneously.
- [x] **VERIFIED:** bare “search my files” and “search my documents” ask one
  local follow-up. Document search remains inside `~/Documents`; all searches
  inspect filenames only.
- [x] **VERIFIED:** deliberate media titles receive one immediate “Let me spin
  that track.” acknowledgement. Lookup has no artificial pre-search pause,
  waits 1.5 seconds only after a valid result, tries enabled Brave first and
  enabled Firefox only as a bounded fallback.
- [x] **VERIFIED:** provider-backed searches share a cooldown, make no
  automatic retries and do not bypass CAPTCHAs, rotate networks or simulate
  browsing activity.

## GUI, backup and maintenance

- [x] **VERIFIED:** fresh setup offers Recommended, All or Custom. Recommended
  includes only detected everyday apps, including supported Notes, Mail and
  Calendar choices when present. Updates preserve the saved policy.
- [x] **VERIFIED:** Overview shows a compact health banner and Speech,
  Listener and Commands status. Applications is searchable; Defaults is a
  separate accessible page; Maintenance precedes Updates.
- [x] **VERIFIED:** private export contains reviewed persistent settings,
  preferred apps, spoken names, personal commands, shortcuts and normal
  reading speed. It excludes code, logs, recordings, models, secrets and the
  temporary 2× marker.
- [x] **VERIFIED:** same-machine backup, inspection, atomic restore and
  automatic rollback remain separate from portable export.
- [x] **VERIFIED:** uninstall is component-scoped. Removing Qwen, retained
  settings/history or the full OVOS environment requires a separate explicit
  choice; Speech Note is not silently removed.

## Historical failures that must not return

- **HISTORICAL:** copied virtualenv scripts pointed at deleted staging paths;
  some launchers became zero bytes during a manual repair.
- **HISTORICAL:** a partial stack upgrade left Adapt 1.0.9 with newer Workshop,
  and NumPy 2 selected an incompatible TFLite OpenWakeWord path.
- **HISTORICAL:** stale listener defaults, missing SoundDevice parity, delayed
  cue gating and service-start volume snapshots broke wake, hotkey, captured
  speech or volume restoration.
- **HISTORICAL:** DDG/application fallbacks stole unmatched commands and
  prompted replies; Media ran after Alerts; reading lock contention was
  reported as Speech Note startup failure.
- **HISTORICAL:** every detected app was enabled by default and `core-only`
  left the GUI empty. The three current choices and compatible Defaults page
  supersede both states.

Publication is permitted only after every unchecked release blocker above is
closed with the exact commit and artifact evidence.
