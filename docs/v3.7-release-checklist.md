# Jarvis 3.7 release gate

**VERIFIED** is supported by code or an automated test. **PLANNED** requires a
live desktop check. Historical incidents remain in `docs/history/`.

## Behaviour

- [x] **VERIFIED:** direct `Play {title}` still reaches the bounded Media event.
- [x] **VERIFIED:** `play/lay music` asks “What shall I play?” and one reply is
  passed as title data; silence, cancellation and length limits are bounded.
- [x] **VERIFIED:** `pose/poze music` pauses media; bare `pose` is not a command.
- [x] **VERIFIED:** action registry, deterministic vocabulary, Qwen candidate
  selection and the generated Commands GUI share the same action definitions.
- [x] **VERIFIED live:** direct and prompted playback, listening cues, wake-word
  and hotkey capture were exercised on the upgraded desktop. A temporary empty
  transcription was traced to the system microphone being muted, not Jarvis.

## Update and privilege safety

- [x] **VERIFIED:** GUI updates schedule one detached relaunch only after a
  successful installer result and after the old Control Centre exits.
- [x] **VERIFIED:** tray startup remains idempotent.
- [x] **VERIFIED:** update, release and OVOS-bootstrap workspaces are private
  user-owned paths; the whole upstream installer is not run through `sudo`.
- [x] **VERIFIED:** permanent OVOS console launchers are rejected if they retain
  a staging or privileged-temporary shebang.
- [x] **VERIFIED:** custom commands, app selection, defaults, aliases, models,
  OVOS configuration, shortcuts and unlisted private helpers remain preserved.
- [x] **VERIFIED live:** 3.7 installed from the 3.6.1 Control Centre; the updated
  interface loaded and message bus, listener, audio and command services were
  active. Existing application selection and machine configuration remained.

## Release validation

- [x] Complete validation and 340-case non-executing routing benchmark pass.
- [x] Fresh install, upgrade preservation, injected failure, rollback and
  component-scoped uninstall pass.
- [x] Dispatcher and both plugin wheels build with correct metadata.
- [x] Final archive checksum passes and the complete suite passes from a clean
  extraction of that exact artifact.
- [x] Privacy, secret, path, link and documentation scans pass.
